# vesdorastudios.github.io

Website of Vesdora Studios, served by GitHub Pages at https://vesdorastudios.github.io

- `/` studio home, `/support/` support and contact
- `/<game>/` a game's page, `/<game>/privacy/` its privacy policy (English, with `tr/ de/ es/ fr/ it/ pt-br/ sv/ ja/` translations)
- `/app-ads.txt` AdMob authorized sellers, shared by every game of the studio

Plain HTML and one stylesheet (`assets/style.css`); no build step.
